# Ícones dos artefatos

Coloque aqui PNGs (embutidos no build; se faltar algum, o mod usa um ícone gerado):

| Arquivo | Uso |
|---|---|
| `dizimo_selecionado.png` | Artefato do Dízimo ligado |
| `dizimo_desmarcado.png` | Artefato do Dízimo desligado |
| `taxade_selecionado.png` | Artefato Taxade ligado |
| `taxade_desmarcado.png` | Artefato Taxade desligado |
| `ressurreicao_selecionado.png` | Artefato da Ressurreição ligado |
| `ressurreicao_desmarcado.png` | Artefato da Ressurreição desligado |
| `vazio_selecionado.png` | Artefato do Vazio ligado |
| `vazio_desmarcado.png` | Artefato do Vazio desligado |
| `comunismo_selecionado.png` | Artefato do Comunismo ligado |
| `comunismo_desmarcado.png` | Artefato do Comunismo desligado |
| `capitalismo.png` | Ícone dos 3 itens Capitalismo (branco/verde/vermelho), 256x256 |

Formato: PNG quadrado, RGBA com fundo transparente, 128x128 (como os artefatos do jogo).
O "desmarcado" é a mesma arte escurecida/dessaturada.
